# Project naming

Название проекта строго писать `pz3d`, только строчными буквами, в интерфейсах, сообщениях пользователю, документации и новых записях журнала изменений. Не использовать варианты `PZ3D`, `Pz3d` и другие. Существующие технические идентификаторы, имена классов, ключи API и пути сохранять в точном регистре, необходимом для работы; это не варианты написания названия.
